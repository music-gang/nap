# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it
privately through GitHub:
[Report a vulnerability](https://github.com/music-gang/nap/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You
can expect an acknowledgement, and a fix or an explanation, on a best-effort
basis: Nap is maintained by a small team.

## Supported versions

Only the latest release is supported, and while Nap is at `v0` that means the
latest minor: a fix goes into a new patch or minor of the current line, never
into an older one.
